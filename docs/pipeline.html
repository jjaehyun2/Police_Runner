구조

네 개 층이 각자 하나씩만 책임집니다

층을 나눈 이유는 교체 가능성입니다. 정책을 학습된 것으로 바꿔도 환경과 화면은 그대로 씁니다.

보상

학습 정책이 들어올 자리

지금 데모는 규칙기반이지만, 보상 구조는 학습을 전제로 이미 정리해 두었습니다.

경찰 i 가 한 스텝에 받는 보상
r_i =  w_own  · Δ(도로 통과시간, 자차 → 도주자)      ← 직선거리 아님
     + w_team · Δ(팀 최소 통과시간)   [argmin 경찰만]  ← 크레딧 분배
     − w_time                                       ← 스텝 비용
     + capture_bonus · share_i                       ← 체포자 1.0 / 지원 0.25
     − safety_penalty_i                              ← 위험도로 통과 · 몰아붙이기
     + λ · G(z, [s_i, a_i])                          ← GMAN 밀집보상 (설계만)
항상태왜 이렇게 되었나
통과시간 거리구현유클리드 거리는 도로망에서 모든 이동이 손해인 지점을 만들어 경찰을 세웁니다
대칭 후퇴구현후퇴에 1.6배 벌점을 주면 탐색의 기대값이 정지보다 낮아집니다
크레딧 분배구현팀 보상을 6대에 똑같이 주면 원거리 경찰은 아무것도 안 해도 같은 보상을 받습니다
안전 페널티구현멘토링 지적 — 보상함수에 안전 항이 없었습니다
GMAN 밀집보상설계검거는 드물게 일어납니다. 생성자가 만든 밀집 신호로 보완 — 학습은 다음 단계
기준 연구에서 가져오지 않은 것

분산 DQN은 채택하지 않았습니다. 행동 마스킹·비동기 결정·감사 인프라가 전부 MAPPO에 물려 있고, 논문의 근거는 PPO 대비 검거시간 −5.47% 한 줄입니다. 덧붙여 GMAN 밀집보상은 DQN을 요구하지 않습니다 — 보상 가산 형태로 붙습니다.

검증

파이프라인을 만들며 잡은 결함

전부 결과가 존재하지만 그 결과가 거짓인 종류입니다. 성능 수치보다 이쪽이 중요합니다.

결함증상처리
사라진 차량을 탈출로 집계 SUMO가 경로를 다 쓴 차량을 제거 → 아무도 플레이하지 않은 에피소드가 도주자 승리로 기록 추적 차량은 경로 유지, 그래도 사라지면 VOID로 집계 제외
도주자 경계 스폰 15스텝 만에 탈출로 종료 지도 안쪽에만 배치
모든 신호가 초록 교차로 상태에 초록이 하나라도 있으면 초록 판정 → 도시 전체 초록 우세 현시 기준 (빨강 37 / 초록 47)
화면 켜두면 데모가 죽음 윈도우는 열린 파일 위로 rename 거부 → PermissionError 재시도와 폴백 (2,736회 동시 폴링 무실패)
브라우저가 옛 화면 코드 사용 기능을 추가해도 화면에 안 나타남 — 구현 안 된 것과 구분 불가 서버가 no-store 전송
경찰 3 km 밖 스폰 6대 중 일부가 에피소드 내내 이동만 하다 끝남 — 실제로 뛴 전력은 4대 사건 반경 1.2 km 링 배치 (평균 1,954 m → 735 m)
이 프로젝트가 이미 겪은 일

과거 이 레포에서 승률 100%가 나온 적이 있고, 원인은 종료 판정 순서 버그였습니다. 그때 두 버전의 결과가 통째로 폐기됐습니다. 위 첫 번째 결함은 정확히 같은 계열이라 반드시 잡아야 했습니다.

이건 학습된 정책이 아니라 규칙기반 포위의 성적입니다. 이 프로젝트에서 가장 강한 기존 베이스라인의 SUMO판이고, 학습 정책이 넘어야 할 기준선입니다.

발표에서는 이렇게: 학습 정책 수치는 재학습 후 확정합니다. 지금 보여드리는 것은 그 수치를 만들 메커니즘이 실제 교통 속에서 작동한다는 사실입니다.

두 화면의 역할이 다릅니다

관제 화면은 차량을 과장해 그려서 포위가 되고 있다를 한눈에 보여줍니다. SUMO-GUI는 실제 축척이라 도시 전체를 보면 차가 점보다 작지만, 확대하면 차선·신호 현시·차간거리를 그대로 볼 수 있습니다. 발표에서는 관제 화면으로 설명하고, 질문이 나오면 SUMO 창을 여는 순서를 권합니다.

자세한 설계 배경은 process.md, 실행 옵션 전체는 RUNNING.md. 기준 연구 — Li, Yang, Zhang et al., Distributed Generative Multi-Adversarial Reinforcement Learning for Multi-Vehicle Pursuit, Intelligence & Robotics 3(3):436-452, 2023. 해당 레포에 라이선스 표기가 없어 코드를 복사하지 않고 논문 서술 기반으로 재구현했습니다.
