# 관제실 대시보드

SUMO-GUI 옆에 띄워 놓는 경찰 추격 시뮬레이션 관제실(control room) 패널.
FastAPI가 정적 페이지 하나(`index.html`)와 상태 조회 엔드포인트 하나(`/api/state`)만
제공하는 최소 서버다.

## 실행

```bash
cd scripts/sumo_demo/dashboard
py -3.12 server.py --port 8020
```

또는 uvicorn을 직접 사용:

```bash
py -3.12 -m uvicorn server:app --port 8020
```

브라우저에서 `http://127.0.0.1:8020/` 접속. 페이지가 500ms마다 `/api/state`를
폴링해서 화면을 갱신한다.

옵션:

- `--port` (기본 8020)
- `--host` (기본 127.0.0.1)
- `--reload` (개발용, `index.html`/`server.py` 변경 시 자동 재시작 — 문자열 임포트 대상으로
  실행되므로 이 폴더 안에서 실행해야 함)

## 상태 파일 계약

서버는 요청마다 `scripts/sumo_demo/out/state.json`(이 폴더의 부모인 `out/`)을
다시 읽어 그대로 반환한다. 데모 러너 프로세스와 서버는 코드로 결합되지 않고,
오직 이 파일을 통해서만 통신한다 — 러너가 매 스텝(또는 원하는 주기)마다 이
경로에 최신 상태를 덮어쓰면 된다.

- 파일이 없으면 서버는 `{"status": "waiting"}`을 반환하고, 대시보드는 "대기 중"
  오버레이를 보여준다.
- 파일이 있지만 JSON 파싱에 실패하면(러너가 쓰는 도중 읽은 경우 등) 마찬가지로
  대기 상태로 대체한다 — 대시보드가 깨지지 않는다.
- 쓰기는 원자적이지 않아도 된다. 폴링 주기(500ms) 안에서 어쩌다 한 번 파싱
  실패가 나도 다음 폴링에서 정상 상태로 복구된다.

### 스키마

```json
{
  "status": "running|captured|escaped|timeout|waiting",
  "step": 128,
  "sim_time_s": 128.0,
  "elapsed_str": "02:08",
  "background_vehicles": 297,
  "containment_pct": 62.4,
  "nearest": {"officer": "P3", "distance_m": 187.4},
  "officers": [
    {"id": "P0", "edge": "대덕대로", "action": "동측 진입", "distance_m": 187.4, "state": "이동|대기|차단"}
  ],
  "fugitive": {"edge": "유성대로", "speed_kph": 41.2},
  "latency": {"p50_ms": 5.4, "p99_ms": 11.3},
  "tick_s": 1.0,
  "events": [{"t": "02:08", "msg": "P4 경로 재계획"}]
}
```

`status: "running"`은 화면에서 `containment_pct >= 50` 기준으로 "추적중"과
"포위중" 두 배지로 갈라서 보여준다(스키마의 5개 값을 화면이 요구하는 5개 한글
라벨에 맞추기 위한 매핑). `officers[].state`가 없거나 예상 밖 값이면 칩은
"대기" 취급된다.

## 화면 구성

- **상단 바**: 관제실 타이틀, 도주차량 현재 도로/속도, 연결 상태 표시(수신 중이면
  청록색 점이 깜박임 — `prefers-reduced-motion`이면 정지).
- **상황 요약(5개 타일)**: 경과 시간 + 스텝, 배경 차량 수, 최근접 경찰 ID와 거리,
  포위 완성률(20칸 계기형 미터 — 50% 미만 청록/50~85% 호박색/85% 이상 녹색),
  상태 배지.
- **6대 권고 테이블**: 도주자까지 거리가 가까운 순으로 정렬. 각 행은 상태(이동/
  대기/차단)에 따라 왼쪽 색 띠 + 상태 칩으로 이중 인코딩. 최근접 경찰 행은
  옅은 배경으로 강조.
- **지표**: 추론 지연 p50/p99, 갱신 주기, 시뮬 스텝을 2x2 타일로.
- **이벤트 로그**: 최근 12건, 최신 항목이 위로 오도록 역순 렌더링, 시각(모노스페이스) +
  메시지.
- 데이터가 없으면(`status: "waiting"` 또는 파일 부재) 전체화면 오버레이로 "대기 중"을
  보여주고 나머지 패널은 마지막 상태 그대로 어둡게 덮인다.

## 디자인 노트

다크 오퍼레이션 콘솔 톤. 배경은 순검정이 아닌 청회색 계열 그래파이트
(`#0a0d10` 페이지 / `#12171d` 패널)로 SUMO-GUI 창과 나란히 둬도 서로 부딕치지
않게 했다. 상태색은 5가지 역할로 고정: 청록(추적/이동 — 진행 중인 신호),
호박색(포위중/차단 — 조여드는 상황), 녹색(검거 — 성공 종결), 빨강(탈출 — 실패
종결), 슬레이트 그레이(시간초과/대기 — 중립). 숫자는 전부 모노스페이스 +
`tabular-nums`로 자릿수가 흔들리지 않게 했다. 한글 폰트는 Pretendard →
맑은 고딕 순으로 폴백(CDN 없이 시스템 폰트만 사용).
