# 연속 환경 전면 재설계 계획

## 마지막 업데이트: 2026-07-02

## 현재 문제점

기존 연속 환경의 행동 공간이 비현실적임:
- 360° 자유 방향 이동 → 실제 도로에서 불가능
- 에이전트가 도로 방향을 학습하는 데만 대부분의 에피소드 소모
- 25,500 에피소드 돌려도 경찰 승률 20~25% 수준에서 정체

## 재설계 핵심 원칙

**"도로 위 차량"으로서의 물리적 제약을 환경에 내장한다.**

### 도로 모델

```
[도로 세그먼트]
┌──────────────────────────────────┐
│  차선1  ●→  (진행 방향 고정)      │  폭: 10~20m
│  차선2       (반대 차선 없음*)    │  
└──────────────────────────────────┘
              │
         [교차로]  ← 방향 전환 가능 지점
              │
```

*양방향 도로가 아닌, 방향이 있는 도로 세그먼트로 모델링

### 에이전트 상태

```python
@dataclass
class VehicleState:
    agent_id: str
    segment_id: int           # 현재 위치한 도로 세그먼트
    progress: float           # 0.0~1.0 (세그먼트 내 종방향 진행률)
    lane_offset: float        # -1.0~1.0 (횡방향, 도로 중심 기준)
    speed: float              # 현재 속도
    agent_type: str           # "police" | "fugitive"
```

### 행동 공간 (하이브리드)

1. **도로 위 (매 스텝)**:
   - 가속/감속: 이산 3개 (가속, 유지, 감속) 또는 연속 (-1~1)
   - 차선 변경: 이산 3개 (좌, 유지, 우)

2. **교차로 도달 시**:
   - 방향 선택: 이산 (직진, 좌회전, 우회전, 유턴) — 연결된 도로만 선택 가능

### 이산 행동 공간으로 단순화 (추천)

속도 고정이면 행동 = **교차로에서 어느 방향으로 갈지**만 결정:

```python
# 행동 공간: MultiDiscrete 또는 Discrete
# 매 스텝: "현재 도로에서 계속 직진" (action=0)
# 교차로 도달 시: "연결된 도로 N개 중 선택" (action=1~N)
```

이러면 사실상 **이산 환경의 확장판**이 됨:
- 노드 = 교차로
- 엣지 = 도로 세그먼트 (길이, 폭, 방향 속성 포함)
- 위치 = 세그먼트 위 연속 좌표 (progress 0~1)

### 이산 환경과의 차이점

| 항목 | 이산 환경 | 재설계 연속 환경 |
|------|-----------|-----------------|
| 위치 | 노드 ID (정수) | 세그먼트 + progress (연속) |
| 이동 | 한 스텝에 노드 1개 점프 | 매 스텝 도로 위 연속 이동 |
| 행동 | "어느 인접 노드로?" | "교차로에서 어느 도로로?" |
| 시간 | 스텝 = 이동 1회 | 스텝 = dt 시간 경과 (교차로 간 여러 스텝) |
| 거리 | 홉 수 | 유클리드 거리 (도로 경유) |
| 추격 | 같은 노드 = 체포 | 반경 내 접근 = 체포 |

## 구현 계획

### Phase 1: 환경 재구축
1. `RoadNetwork2D`: 방향 있는 세그먼트 + 교차로 그래프
2. `VehicleModel`: 세그먼트 위 연속 이동 물리
3. `RoadPursuitEnv`: Gymnasium 환경 (교차로 선택 = 이산 행동)

### Phase 2: 학습
- 행동이 이산이므로 기존 MAPPO (Categorical) 재활용 가능!
- 관측: 자기 위치(segment, progress), 도망자 위치, 동료 위치, 도로 구조 정보
- 이산 환경 모델의 가중치 전이 가능성 있음 (관측 구조 비슷하면)

### Phase 3: 시각화
- 2D 도로 위에 차량 위치를 실시간 표시
- 도로 폭, 교차로, 체포 반경 시각화

## 예상 효과

- 학습 속도 대폭 개선 (유효하지 않은 행동 없음)
- 이산 환경 수준의 수렴 속도 (비슷한 행동 공간 크기)
- 현실 도로에 훨씬 가까운 시뮬레이션
- 기존 이산 모델 지식 활용 가능
